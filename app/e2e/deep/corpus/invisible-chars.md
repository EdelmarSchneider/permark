# Invisible characters

Zero width space between letters: a​b​c (three letters, two zero width spaces).

Zero width joiner emoji: 👩‍💻 👨‍👩‍👧 🏳️‍🌈 and a flag 🇧🇷.

Zero width non-joiner: می‌خواهم.

Soft hyphen: super­cali­fragilistic­expialidocious.

No-break space: 10 km, narrow no-break: 5 %, and a word joiner: a⁠b.

Right-to-left mark inside text: abc‏def, and a left-to-right mark: abc‎def.

Byte order mark in the middle: a﻿b.
