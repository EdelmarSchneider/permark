# Third-party notices

This is the placeholder in a development checkout. In a release build this file is replaced by the licenses of every
third-party Rust crate, npm package and C library inside PerMark, made at build time (`npm run notices` in `app/`,
see `app/scripts/third-party-notices.mjs`).

The same lists are in the source repository: `app/src-tauri/Cargo.lock` and `app/package-lock.json`.
