# Third-party notices

This is the placeholder in a development checkout. In a release build this file is replaced by the licenses of every
third-party Rust crate, npm package, C library and data file inside PerMark, made at build time (`npm run notices` in
`app/`, see `app/scripts/third-party-notices.mjs`).

The same lists are in the source repository: `app/src-tauri/Cargo.lock`, `app/package-lock.json` and, for the agent list
of the Assistant plugin (from the Agent Client Protocol registry, Apache-2.0),
`app/src-tauri/crates/plugins/acp/agents/registry.json`.
