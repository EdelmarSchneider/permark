## Getting started

Open a folder, pick a document in the tree, read it. Links between documents work like a wiki: use Alt+Left to go back.

![PerMark logo](img/logo.png)

## Shortcuts

| Keys         | Action          |
| ------------ | --------------- |
| Ctrl+F       | Find in page    |
| Alt+Left     | Back            |
| Ctrl+= / Ctrl+- | Zoom         |
