Privacy policy

Last updated October 15, 2026. This applies to TrailMark, the desktop app, on every platform it runs on, including the version in the Microsoft Store.

In short

TrailMark has no account and no sign-in, and it collects no data about you or about how you use it. It has no analytics and no tracking. The developer receives nothing from the app.

What stays on your computer

Everything you work with stays on your computer:

  • Your documents. TrailMark reads the folders you open, and changes a file only when you save an edit or ask it to rename, move or delete one.
  • Your tags, descriptions and comments, and which documents you have read. They are kept in TrailMark's data folder on your computer, or in the project's .trailmark folder if you chose to keep them there.
  • Your settings, your recent folders and the position of the window.

None of it is sent anywhere by TrailMark.

What TrailMark does with the network

  • Update check. The installers of TrailMark that are not from the Microsoft Store check for a new version a few seconds after the app starts, and when you ask it to. To do that the app requests a small file named latest.json from GitHub Releases, and, if you choose to update, downloads the update from there. The request carries nothing about you or your documents. GitHub receives it the way any web server receives a visit, under GitHub's privacy statement. The Microsoft Store version does not do this at all: the Store updates it, and the app makes no update requests.
  • Images in your documents. If a document you open shows an image from a web address, TrailMark loads that image from there, as a web browser or any Markdown viewer would. Links you click open in your default browser.

That is all: TrailMark itself does not contact any other server.

The agent connection

TrailMark can tell an AI agent what you are looking at, so that you can say "rewrite this paragraph" and the agent knows which one. This connection is off by default and you turn it on for one project at a time, in Settings, Agent connection. It is local only: TrailMark talks to programs on your computer and has no server that listens on the network.

The agent you connect is another program, and it is up to you. It may send what it reads from TrailMark (your selection, your comments, search results) to its own AI service, the way it would send anything else you show it. What that service does with it is between you and that service, under its terms and privacy policy. Turn the connection off, in one click from the status bar, and the agent sees nothing.

Children

TrailMark has no accounts and collects no personal data, from children or from anyone else.

Changes to this page

If this changes, the new text is published on this page, with a new date at the top.

Contact

Questions about privacy can be asked in the open, on TrailMark's GitHub issues. The source code of the app is public, so everything on this page can be checked there.
