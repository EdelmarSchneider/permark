Privacy policy

Last updated October 20, 2026. This page covers PerMark, the desktop app, in every build: the versions from GitHub, the Microsoft Store and the snap. It also covers this website.

In short

PerMark has no account, no telemetry and no tracking. It goes online only to check for its own updates (in the versions you download from GitHub; the Microsoft Store and the snap update PerMark for it), and when you ask: a picture from the web, or the optional vocabulary of the Token count plugin. Your documents do not leave your computer through PerMark. An AI agent you connect is a separate program: what it sends online is up to that agent.

What PerMark does not do

  • It has no account and no sign-in.
  • It has no telemetry, no analytics and no crash reporting.
  • It does not send your documents over the internet. When you turn on the agent connection, it gives parts of them only to an agent on your own computer.

What stays on your computer

  • Your documents. PerMark reads the folders and files you open. It changes them only when you act in it: for example, when you save an edit, revert a change in Review, add a picture, or create, rename, move or delete a file (and, if you agree, the links to it in other documents). Notes save themselves as you type, as plain Markdown files in a folder you can see.
  • What you add in PerMark. Your tags, descriptions and comments, and which documents you have read. PerMark keeps them in its data folder in your user profile, or in the project's .permark folder if you chose to keep them there.
  • Your settings, your recent folders, and your windows and tabs.

PerMark sends none of this over the internet.

What these requests carry:

  • The update check and the update download name only the update library and its version. They do not carry your PerMark version.
  • Like any web request, each one shows your IP address to the server it reaches.
  • The vocabulary and picture requests send no cookies.
  • A web picture tells its web server your IP address and that the picture was viewed.
  • PerMark checks each update against its signature before it installs it, and checks each vocabulary file against a fixed fingerprint (SHA-256).

What is not a network call

  • Diagrams and math. Mermaid, PlantUML and KaTeX run inside PerMark. PerMark uses no PlantUML server, and it refuses PlantUML lines that would fetch files.
  • Fonts and styles. They come with PerMark. It loads nothing from the web for its own look.
  • Links. A web or email link opens in your browser or mail app. That program goes online, not PerMark.
  • Git. PerMark never runs fetch, pull, push or clone. Its built-in git cannot go online.
  • The agent connection. It talks only to programs on your own computer, and it opens no network port.

Outside PerMark's control

  • PerMark shows its pages through a part of your system: WebView2 on Windows, WKWebView on macOS, WebKitGTK on Linux. These parts have their own services, such as Microsoft Edge updates, which PerMark does not control.
  • In a partial git clone, the git on your computer may download a missing file from the repository's own server when PerMark shows an old version. This has not been verified.

The agent connection

PerMark can tell an AI agent what you are looking at, so that you can say "rewrite this paragraph" and the agent knows which one. The connection is off in every project until you turn it on: choose Share this project with agents in Settings → Integration → Agent connection. Nothing inside a project can turn it on. While it is on, the status bar shows Agent.

  • It is local: it talks only to programs on your computer and opens no network port.
  • The agent reads, shows you a place and marks your comments done. It never edits a file through PerMark.
  • A note reaches an agent only if you share that note.
  • Files listed in .aiignore never reach an agent. PerMark hides secret values by their key names. A secret inside ordinary text is not recognized, so list such files in .aiignore.

The agent you connect is a separate program, and your choice. It may send what it reads through PerMark (your selection, your comments, search results) to its own AI service, as it would with anything else you show it. What that service does with it is between you and that service, under its terms and privacy policy. Turn the connection off, and the agent gets nothing more through PerMark.

This website

This website is hosted on GitHub Pages. When you visit, GitHub receives your request the way any web server does, including your IP address, under GitHub's privacy statement. The site has no analytics, no tracking scripts and no cookies, and it loads its fonts and pictures from its own address.

The Microsoft Store link on this site carries a campaign tag. If you follow it, Microsoft counts, on its side, the Store page views and the downloads of PerMark that came from this site, and shows the developer only the totals. This site sets no cookie for it. What the Store page itself does is covered by Microsoft's privacy statement.

Children

PerMark has no accounts and collects no personal data, from children or from anyone else.
