Got a .md file?

A clean page, not a wall of symbols.

Tables, task lists, diagrams and math show on the page. The details at the top of a file, its front matter, show as a clean card.

Choose light, dark or a softer tone such as Paper or Sage. Pick a comfortable reading width, and jump through long documents with the outline.

Focus mode hides everything but the page.

Write and keep notes

Fix it as it looks. Notes save themselves.

Edit changes the page as it looks, with a toolbar and a / menu. Source shows the raw file, every byte.

In Edit, math, diagrams and HTML are kept as written, and pictures saved next to the file show in View and Source.

Click Notes, next to Settings, and type. No name to choose, no folder to pick, no save prompt. Notes are plain Markdown files you own.

  • Will it take over my files? You choose. PerMark asks once, with Markdown files checked and other types unchecked. On Windows, you confirm it in Windows Settings.

  • Is it free and safe? It is free: no price, no trial and no license key, in every build. It is open source under MIT or Apache-2.0, at your option. Documents are cleaned before they show, and a click on a program never runs it.

Building with AI agents?

See what your AI writes, while it writes.

Keep PerMark open beside your AI tool. Changed passages glow, removed ones leave a marker, and Follow mode opens the document being written.

Live changes lists every file that changed, one entry per file, whatever program wrote it.

Unread dots mark the documents that changed since you last read them, like new mail. Since last visit shows what changed while you were away, even without git.

Decide what stays

Your AI proposes. You decide what stays.

Review shows each change in place. Keep it or revert it, one by one or all at once, since you last read it or since the last commit.

Select a passage and leave a comment. When you turn on the agent connection for a project, your agent reads your comments and marks them done with a reply. It is off until you do.

Only the blocks you change are saved. Every other byte stays as its author, or agent, wrote it.

  • "Git diff already shows me the changes." Git diff compares with the last commit. PerMark also shows what changed since you last read each document, even after the agent has committed, and you keep or revert each change.

Around your Markdown

Markdown at the center, not alone.

Markdown leads, and many files around it open too: config files, data and code, pictures, audio and video. Not every audio or video format plays.

Config files such as TOML, YAML and .env open as clean sheets of keys and values. Change a value, and only those bytes change. Secret values are masked in the sheet.

Agent files such as AGENTS.md and CLAUDE.md open with no setup. Prompt tags fold as blocks, and TOON files open as tables.

Privacy

Yours, and private.

No account, no telemetry, no tracking.

PerMark goes online only to check for its own updates (installer versions; the Store and snap update it instead), and when you ask: a picture from the web, or the optional token-count vocabulary. Your documents never leave your computer through PerMark. An AI agent you connect is a separate program: what it sends online is up to that agent.

Sharing with an agent is off in every project until you turn it on, and the connection stays on your computer.

What PerMark is not

  • Not an agent. It does not run, host or replace your AI. It shows what your AI writes, and you decide what stays.

  • Not a code editor. No code completion, refactoring, build, run or debug. Real code work opens in your own editor.

  • Not a cloud service. No account, and no server of ours holds your documents.

Install

Get PerMark.

  • Windows

    The Microsoft Store, which keeps PerMark up to date. Or the -setup.exe from GitHub Releases.

  • macOS

    The universal .dmg (Apple silicon and Intel) from GitHub Releases.

  • Linux

    The .AppImage, .deb or .rpm from GitHub Releases, or the snap (64-bit Intel and AMD):

    sudo snap install permark

PerMark 0.6 was tested by hand on Windows; the macOS and Linux builds are checked automatically. The downloads from GitHub are not code-signed, so your system may warn you when you install or open PerMark. Copies from GitHub check for their own updates; the Store and the snap update theirs.

The interface speaks English, Português (Brasil), Español, Deutsch, 简体中文 and Italiano.

Why Markdown

Markdown was made so that plain text reads well as it is. AI tools write it for the same reason: it is clear enough for a person and structured enough for a machine.

A Markdown file is plain text that any app and any AI can open, and it stays yours.

New in 0.6: tabs and many windows, config files as clean sheets, review of code and text files, and a Plugins page to turn off what you do not need. Every change is in the CHANGELOG.
