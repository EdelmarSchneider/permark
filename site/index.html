Why TrailMark

Your agents write the docs. You still have to read them.

Specs, plans, research notes, reports: AI tools produce a lot of Markdown. TrailMark closes the gap between the documents they write and you, the human who has to read, check and steer them.

  1. 1

    Raw text is tiring

    Reading long Markdown as plain text in a terminal or code editor wears you down. Tables, diagrams and math deserve to be rendered.

  2. 2

    One file at a time

    Preview extensions render a single file and lose the bigger picture: links, folders, and how documents relate.

  3. 3

    Changes slip past you

    Agents edit and commit every few minutes. Without help, you can't tell what moved since you last looked.

Features

Everything you need to read what your tools write

  • Reading that feels like a book

    GitHub-flavored Markdown with Mermaid, KaTeX math, alerts, footnotes and highlighted code. Frontmatter becomes a clean metadata card. Light and dark themes, zoom, three reading widths and a focus mode.

  • Navigate like a wiki

    Open a folder for IDE mode or a single file for a distraction-free reader. Relative links and images resolve in the app, with back and forward and quick open. An outline follows you through long documents, and an Explorer filter keeps a code repository down to its docs.

  • Follow your agents live

    Docs reload without losing your scroll position. Changed blocks glow, removed blocks leave a marker, and a live feed shows every file being touched, across git worktrees too.

  • Find anything, to the section

    Section-level full-text search shows file › heading › snippet and jumps to the exact spot. Accent- and case-insensitive, with light stemming, updated as files change.

  • Tags and descriptions

    Give any file a one-line description and tags, read from frontmatter or added in the app without touching your files. Browse by tag, filter search with tag:needs-review, and see descriptions in the tree and in results.

  • Edit without fear

    A visual editor and a source editor that rewrite only the blocks you changed. If an agent changes the file while you edit, you choose: reload theirs or keep mine. Images you paste land in assets/.

  • Move files, keep your links

    Rename, move and delete from the Explorer. TrailMark updates the links and images that point to a file, shows you the change first, and puts everything back with one Ctrl+Z.

  • Git-aware

    Badges for modified, added and untracked files. Review changes since your last visit or since HEAD, even when the agent already committed. Clear banners for rebases and merges.

  • Close the loop with your AI

    Copy a reference like @docs/plan.md, or a quoted selection with its path and section, ready to paste into any AI chat or CLI. The template is yours to configure.

Zero footprint by default. State lives in your user profile. Opt in to a shared .trailmark/ folder only if you want settings and tags to travel with the project.

Follow mode

Follow your agents live

Leave TrailMark open next to your terminal. As an agent writes, you see exactly where.

  • Changed blocks glow softly, then fade
  • Removed blocks leave a marker you can expand
  • One feed entry per file, bursts grouped, git checkout storms collapsed
  • Follow mode opens the doc being written, and never jumps while you're selecting
  • Jump between changes with F7 and Shift+F7

Retry policy

Requests are retried up to three times. Only idempotent calls are retried automatically.

Backoff starts at 200 ms and doubles on each attempt, capped at 5 s, with ±20% jitter.

− 1 block removed

Timeouts are reported to the caller as RetryExhausted.

Editing

Edit without fear

Fix a paragraph, add a table, paste a screenshot. TrailMark rewrites only the blocks you changed, so the file stays as its author wrote it and your diff stays small.

  • Visual or Source. A WYSIWYG editor with a toolbar and a / block menu, or a Markdown editor with highlighting. Switch with Ctrl+Alt+E, keeping your place and your unsaved work
  • Only your changes are written. Every other byte, line ending and blank line stays as it was, and a save without an edit writes the very same file
  • Safe next to agents. If something changes the file while you edit, choose Reload theirs or Keep mine. A save never overwrites a version you haven't seen
  • Nothing lost quietly. Unsaved blocks carry a bar in the margin, and leaving asks to save, discard or keep editing
  • Locked blocks stay exact. Front matter, raw HTML, math and diagrams are shown as they read, with Edit in Source one click away
  • New files and images. Ctrl+N names a file in the tree and opens it ready to type. Pasted images are saved in assets/ next to the document

Tags and descriptions

Find the right file by what it is

Give files a one-line description and a few tags, and browse a big folder the way you think about it: "everything that needs review", "all the character sheets".

  • Frontmatter and app tags. Tags written in a file's tags: are read automatically. Tags you add in the app never touch your files
  • Shared when you want. Added tags live in .trailmark/meta.toml, plain text you can commit so teammates and agents can read it
  • A Tags view. Every tag with its file count. Click one, or Ctrl+click several to narrow the list
  • Everywhere you look. tag:needs-review works in quick open and search, and descriptions show in the tree, quick open and results

Tool-agnostic

Works with whatever writes your Markdown

Install

Up and running in a minute

Download

Prebuilt installers for Windows, macOS and Linux. TrailMark updates itself: when a new version is out, you get a one-click restart.

Latest release

Then open a project

trailmark                # welcome screen, recent projects
trailmark .              # this folder, IDE mode
trailmark docs/plan.md   # one file, simple mode

Or drag a folder or a .md file onto the window.

Build from source

Requires Rust, Node.js 20+ and the Tauri prerequisites.

git clone https://github.com/EdelmarSchneider/trailmark.git
cd trailmark
npm install
npm run tauri build

A Tauri 2 app: a Rust core with a Svelte UI in the system webview. Small installer, low memory.

Roadmap

What's next

  1. v0.2 Released
    • Edit in a visual or a source editor that rewrites only the blocks you changed, and shares a file safely with agents
    • Tags and descriptions, an Explorer filter, three reading widths and an outline for long documents
    • File operations that update your links, with undo
  2. v0.2.1 Released
    • Your language: Português (Brasil), Español and Deutsch
    • "Open with TrailMark" in the Windows file manager, and one Read | Visual | Source switch
    • A window that remembers its place, and an Explorer for workspaces of several repositories
  3. v0.3
    • Search everywhere (Ctrl+T): files, sections, tags and commands in one box
    • Unread markers, clickable code references and "Open with TrailMark" on macOS and Linux
  4. v0.4
    • Your agent sees what you see: an optional, local connection that tells any coding agent which section you are reading and what you selected
    • Review notes on passages that your agent picks up, and "where is X described?" answered by TrailMark
  5. v0.5
    • Semantic search, local, offline and multilingual: ask for "retry policy" and find the section that describes it, whatever words it uses
  6. Later
    • Ideas being explored, with no promises: spec-driven workflows, a rendered diff against your last read, and backlinks
