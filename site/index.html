Got a .md file?

A .md file is a document. Open it like one.

Your AI, a colleague or a download gives you a .md file. PerMark shows it the way it was meant to look, lets you fix it, and never writes it until you save.

  • It reads like a page. Tables, checklists, highlighted code, Mermaid diagrams, math, alerts and footnotes. Light and dark themes, three reading widths and a focus mode
  • Links work. Links between documents open in the app, with back and forward, and images show where they belong
  • An outline for long documents. The headings sit in a panel beside the page: the section you are reading is marked, and a click jumps to any other
  • Visual or Source. Edit like a word processor, with a toolbar and a / block menu, or in the Markdown itself. One click switches, keeping your place and your unsaved work
  • Only your changes are saved. Every other byte of the file stays as it was. If something else changes the file while you edit, you choose Reload theirs or Keep mine
  • Make it your .md app. PerMark is listed under Open with for Markdown files and never takes over: whether it becomes your app for .md files is up to you

Notes

Notes that save themselves

Press Ctrl+Shift+N in PerMark and type. There is no name to choose, no folder to pick and no save prompt.

  • Type and close. A note saves as you type, and closing never asks. Each one is a plain .md file in your Documents folder
  • Pins. Pin the notes you keep for months, and open them with Ctrl+1 to 9
  • Earlier versions, and Undo. Show earlier versions brings back an earlier text, and a deleted note goes to the system trash, with Undo
  • Copy a prompt to your AI. Copy puts the exact Markdown on the clipboard, ready to paste into any AI chat
  • Any file, too. A Markdown or text file you open from anywhere is listed beside your notes, opens in Read, and is written only when you press Ctrl+S
  • Ordinary files. Edit a note with any other tool and PerMark picks the change up

Build with AI agents?

The IDE for directing your agents.

Your agents write the docs. You still have to read them. PerMark doesn't run your agent. It's where you watch, review and steer what it writes.

Follow mode

Follow your agents live

Leave PerMark open next to your terminal. As an agent writes, you see exactly where.

  • Removed blocks leave a marker you can expand
  • One feed entry per file, bursts grouped, git checkout storms collapsed

Agent connection

Your agent sees what you see

Say "rewrite this paragraph" or "go through my comments", and your agent knows which document, which section and which words you mean. It works with any tool that speaks MCP.

  • Where you are. The open document, the section on screen and your selection, plus the documents that changed since you read them
  • Comments. Select a passage, press C and write. Your agent lists the open comments and marks them done with a short reply
  • "Where is X described?" Your agent searches the same section index as you, and can open a place for you without taking your focus
  • Yours to switch on. Off by default, per project, local only, and visible in the status bar while it is on. An agent never edits through PerMark

Why Markdown

Markdown was made for readers. So is PerMark.

Markdown was designed in 2004 so that plain text reads well as it is. Twenty years later, AI adopted it for the same reason: it is structured enough for a machine, and clear enough for a person. A Markdown file can hold most of what a document needs (headings, tables, checklists, diagrams, math) as plain text that any app, and any AI, can open, and that stays yours. PerMark is built to do it justice.

It is also our opinion that many documents that live in Word or PDF today would be better as Markdown: smaller, comparable line by line in git, readable by any AI, and never locked inside one app.

Privacy

Yours, and private

  • Plain files. Your documents stay ordinary files in folders you can see. PerMark keeps its own state in your user profile, unless you ask for a shared .permark/ folder
  • No account, no tracking. PerMark collects nothing about you or your documents, and has no sign-in
  • The agent connection is off until you turn it on. It is per project, and it only talks to programs on your computer. Notes stay private unless you share one
  • Free and open source. Licensed under MIT or Apache-2.0, at your option
  • Windows, macOS and Linux. In English, Português (Brasil), Español, Deutsch and 简体中文
  • Read the details. What the app does with the network, and what it does not, is in the privacy policy

Install

Up and running in a minute

Download

On Windows, the Microsoft Store keeps PerMark up to date. Installers for Windows, macOS and Linux are on GitHub, and they update themselves: when a new version is out, you get a one-click restart.

Get it from the Microsoft Store Installers: latest release

Then open a file or a folder

permark                # welcome screen, recent projects
permark .              # this folder, IDE mode
permark docs/plan.md   # one file, simple mode

Or drag a folder or a .md file onto the window.

Build from source

Requires Rust, Node.js 20+ and the Tauri prerequisites.

git clone https://github.com/EdelmarSchneider/permark.git
cd permark
npm install
npm run tauri build

A Tauri 2 app: a Rust core with a Svelte UI in the system webview. Small installer, low memory.

Features

Everything in PerMark, in detail

  • Reading that feels like a book

    GitHub-flavored Markdown with Mermaid, KaTeX math, alerts, footnotes and highlighted code. Frontmatter becomes a clean metadata card. Light and dark themes, zoom, three reading widths and a focus mode.

  • Notes that save themselves

    Open PerMark, type, close. Notes are plain .md files that you can pin, copy as exact Markdown, move into a project or share with your agent. Files you open from anywhere are listed beside them and written only when you save.

  • Navigate like a wiki

    Open a folder for IDE mode or a single file for a distraction-free reader. Relative links and images resolve in the app, with back and forward. Code references like src/main.rs:42 open the file at the line, in PerMark or your editor. An outline follows you through long documents, and an Explorer filter keeps a code repository down to its docs.

  • Follow your agents live

    Docs reload without losing your scroll position. Changed blocks glow, removed blocks leave a marker, and a live feed shows every file being touched, across git worktrees too. Unread dots mark every document that changed since you read it.

  • Find anything, to the section

    Search everywhere (Ctrl+T) finds files, sections, tags and commands in one box. Section-level full-text search shows file › heading › snippet and jumps to the exact spot. Accent- and case-insensitive, with light stemming, updated as files change.

  • Tags and descriptions

    Give any file a one-line description and tags, read from frontmatter or added in the app without touching your files. Browse by tag, filter search with tag:needs-review, and see descriptions in the tree and in results.

  • Edit without fear

    A visual editor and a source editor that rewrite only the blocks you changed. If an agent changes the file while you edit, you choose: reload theirs or keep mine. Images you paste land in assets/.

  • Move files, keep your links

    Rename, move and delete from the Explorer. PerMark updates the links and images that point to a file, shows you the change first, and puts everything back with one Ctrl+Z.

  • Git-aware

    Badges for modified, added and untracked files. Review changes since your last visit or since HEAD, even when the agent already committed. Clear banners for rebases and merges.

  • Close the loop with your AI

    Turn on the agent connection and your coding agent knows which section you are reading and what you selected. Leave comments on passages for it to pick up, or copy a reference like @docs/plan.md into any AI chat.

  • Open with PerMark

    Listed under Open with for Markdown files on Windows, macOS and Linux. PerMark never sets itself as your default app: that choice stays yours.

  • Your language

    English, Português (Brasil), Español, Deutsch and 简体中文. PerMark follows your system's language, and a setting switches it at once, with no restart.

Zero footprint by default. State lives in your user profile. Opt in to a shared .permark/ folder only if you want settings and tags to travel with the project.
